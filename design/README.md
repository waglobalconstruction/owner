# Фирменный стиль Global

С 02.11.2026 все наши экраны выглядят как флаер по сушке («Финальный лист акции», 26.10.2026). Это офис, приложение бригад, табло и вход. Стиль флаера: белые карточки на небесном фоне, один красный для главного, графитовая полоса с телефоном и лицензией, заголовки Montserrat и текст Inter.

| Файл | Что это |
|---|---|
| `global.css` | Фирменный стиль: цвета (светлая и тёмная тема), шрифты, карточки, кнопки, метки, поля. Все классы начинаются с `g-`, поэтому файл можно вставить рядом со старым CSS, и ничего не сломается |
| `global-logo.svg` | Логотип GLOBAL (здания линиями), обведён с флаера. Цвет берёт от текста (`currentColor`) |
| `style-guide.html` | Страница-образец: цвета, шрифты, все детали, два экрана приложения бригад, тёмная полоса, правила |
| `../dashboard/corporate_office.html` | Корпоративный офис в новом стиле (копия из GitHub) |

## Правила

- **Один красный на экран.** Красными бывают одна главная кнопка и одна главная карточка (как «FREE» на флаере). Всё остальное графитовое и белое.
- **Красная точка в конце заголовка:** «Corporate Office.», «Вход.». На флаере так же: «Dry it. Fix it. Rent it.»
- **Метки капсом над заголовком**: Montserrat 700 с разрядкой. На небесной панели они красные, в карточках графитовые.
- **Внизу тёмная полоса**: телефон (425) 683-3109, почта, «Licensed · Bonded · Insured · WA Lic. CC GLOBACR761B9». Номер лицензии обязателен в любой рекламе (RCW 18.27.100).
- **Статусы своими цветами**: готово зелёным, ждёт жёлтым, просрочено тёмно-красным. Фирменный красный оставляем для главного действия.
- **Без чужих марок в картинках**: никаких Space Needle и настоящих зданий. Только гора, лес и придуманный город.
- **Приложение бригад**: кнопки на всю ширину и высотой 56 px, этапы цепочкой (`g-chain`), дни плитками (`g-tiles`), пункты работы на английском и русском.
